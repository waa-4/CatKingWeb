# CatKingWeb 0.1

Very small forum starter.

Features:
1. Email/password accounts
2. Threads
3. Replies

## Setup

1. Open your Supabase project.
2. Go to SQL Editor.
3. Paste all of `supabase.sql` and run it.
4. In Supabase Authentication settings, decide whether you want email confirmation on or off.
5. Upload `index.html`, `style.css`, and `app.js` to your GitHub Pages repo.
6. Open the site.

The publishable Supabase key is intentionally used in browser code.
Do NOT put a `service_role` / secret key in this project.

## Notes

This version deliberately has:
- one forum section
- no images
- no profiles
- no reactions
- no DMs
- no algorithm/feed
- no admin panel yet

That is intentional for 0.1.
